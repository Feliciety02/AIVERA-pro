# Local lab workflow evidence

This evidence came from `npm run test:e2e` on 13 November 2026. The test created a disposable HTTP server bound to `127.0.0.1`, a separate SQLite database, and seeded test accounts. It ran AIVERA's real HTTP inspector against that self-owned fixture. No third-party host was contacted.

- `assessment.json` contains the exact target URL, scan timestamps, redacted raw HTTP observation, one confirmed cookie finding, the corrected cookie seen at retest, report approval state, scan restart recovery, throttle persistence, and the production CSP check.
- [Local lab assessment PDF](../../../output/pdf/local-lab-assessment.pdf) is a one-page readable summary generated by `py -3 scripts/make_lab_report.py`.

The test roles act through the API. Their actions show that the workflow routes function, but they are scripted actions rather than independent human verification. The temporary database and target are deleted at the end of the test. Nmap, ZAP, external-site scanning, and AI providers were not exercised.
